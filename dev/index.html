QuantitativeGenetics.jl

QuantitativeGenetics.jl fits single-trait animal models by average-information restricted maximum likelihood (AI-REML). Random effects can use a pedigree, a genomic relationship matrix, or an identity relationship. The result provides variance components, fixed effects, and predicted breeding values.

Fit a genomic animal model

Rows of markers correspond to individuals, columns to markers, and values are allele dosages in {0, 1, 2}. This small simulated example supplies one phenotype per individual:

using QuantitativeGenetics, Random, LinearAlgebra, SparseArrays

rng = MersenneTwister(42)
n = 60
markers = Float64.(rand(rng, 0:2, n, 120))
G = genomic_relationship(markers)
relatedness = GenomicRelatedness(G; blend=0.05)

X = ones(n, 1)                # fixed intercept
Z = sparse(1.0I, n, n)        # one record per individual
u = cholesky(Symmetric(G + 0.05I)).L * randn(rng, n)
y = 2 .+ u .+ 0.5 .* randn(rng, n)

result = fit_reml(y, X, [RandomEffect(:genomic, Z, relatedness)])
result.converged
result.σ²                       # random-effect variance
result.σ²ₑ                      # residual variance
blup(result)                    # predicted breeding values
heritability(result)            # estimate and standard error

Inspect result.converged before interpreting estimates. For a pedigree model, use PedigreeRelatedness(sire, dam) in place of GenomicRelatedness; parents must precede offspring and 0 means an unknown parent. See the algorithm walkthrough for details on the mixed model equations and computation.

API reference

QuantitativeGenetics.QuantitativeGenetics — Module
QuantitativeGenetics

Fast quantitative-genetics and genomic-prediction algorithms, built around an ASReml-class AI-REML animal model.

The design priority is speed on the mixed model equations:

  • A⁻¹ is written down directly from the pedigree by Henderson's rules; A is never formed and never inverted, and log|A| comes free from the Mendelian sampling variances.
  • The MME coefficient matrix is assembled by scatter-adding into cached nzval indices — no sparse arithmetic and no allocation per iteration.
  • The fill-reducing ordering places the dense fixed-effect columns last, and the symbolic factorization is computed once for the entire fit.
  • The average-information matrix reuses that factor via k+1 right-hand sides, so second-order information costs no traces at all.
  • The one trace the score does need is supplied exactly by a Takahashi selected inverse, with Hutchinson probing available for very large pedigrees.

Entry point: fit_reml.

QuantitativeGenetics.GenomicRelatedness — Type
GenomicRelatedness(G; blend=0.0, base=I)

Genomic relatedness from a genomic relationship matrix G (e.g. VanRaden's G = ZZᵀ / 2Σpⱼ(1−pⱼ)). One dense Cholesky at construction yields both G⁻¹ and log|G|, so the REML iteration never touches G again.

blend > 0 uses (1−blend)·G + blend·base instead, the standard regularisation that keeps G invertible when markers make it singular or near-singular. base defaults to the identity (a ridge toward independence); pass the pedigree A restricted to the genotyped animals to blend toward pedigree instead. On real marker data a small blend (0.01–0.05) is usually necessary.

G⁻¹ is dense, so a genomic random effect makes the corresponding MME diagonal block dense. That is intrinsic to GBLUP, not an implementation artifact.

source
QuantitativeGenetics.IdentityRelatedness — Type
IdentityRelatedness(q)

K = I of order q: independent random effects, as used for permanent environment, litter, or any i.i.d. grouping factor.

K⁻¹ = I is stored explicitly as a sparse identity so the MME assembly path is uniform, but because it is diagonal it contributes only q scatter-adds and adds no off-diagonal fill. log|K| = 0 exactly.

QuantitativeGenetics.MMEWorkspace — Type
MMEWorkspace

Everything needed to re-solve the mixed model equations at a new set of variance ratios without re-deriving anything structural.

Holds the coefficient matrix C (whose nzval is overwritten in place each iteration), the θ-independent values base_nzval, per-effect scatter indices kidx/kval into C.nzval, the right-hand side, and the cached CHOLMOD factor. See the header of mme.jl for why each of these exists.

QuantitativeGenetics.Pedigree — Type
Pedigree(sire, dam)

A topologically-sorted pedigree with its inbreeding coefficients and Mendelian sampling variances precomputed.

sire and dam are length-q integer vectors; sire[i] / dam[i] give the row index (in 1:q) of animal i's parent, or 0 if unknown. Animals must be ordered so parents precede offspring, i.e. sire[i] < i and dam[i] < i (or 0) for every i. This is checked at construction.

Fields:

  • sire, dam — the parent index vectors (stored as Int32).
  • F — inbreeding coefficient of each animal, by Meuwissen & Luo (1992).
  • d — Mendelian sampling variance of each animal.

d is retained because log|A| = Σ log dᵢ, which lets logdetK return the pedigree log-determinant with no linear algebra at all — see the derivation at the top of this file.

source
QuantitativeGenetics.PedigreeRelatedness — Type
PedigreeRelatedness(ped::Pedigree)
PedigreeRelatedness(sire, dam)

Pedigree relatedness: sparse A⁻¹ by Henderson's rules, with log|A| obtained free from the Mendelian sampling variances (Σ log dᵢ — see pedigree.jl).

A itself is never formed and never inverted, so this is O(q) in both time and storage and scales to very large pedigrees.

QuantitativeGenetics.REMLResult — Type
REMLResult

Outcome of an AI-REML fit.

  • σ² — estimated variance component of each random effect, in the order given.
  • σ²ₑ — estimated residual variance.
  • names — effect names.
  • β — BLUE of the fixed effects.
  • u — BLUP of each random effect.
  • loglik — restricted log-likelihood at the optimum (i.e. −0.5·(−2logL)).
  • iterations, converged
  • vcov — sampling covariance of [σ²...; σ²ₑ], from the inverse AI matrix.
  • se — standard errors of the variance components (sqrt of vcov's diagonal).

QuantitativeGenetics.ainverse — Method
ainverse(ped::Pedigree) -> SparseMatrixCSC{Float64,Int}

Sparse inverse numerator relationship matrix A⁻¹ by Henderson's (1976) rules, built directly from the pedigree without ever forming A.

Each animal i with Mendelian variance dᵢ contributes 1/dᵢ to A⁻¹[i,i], −1/(2dᵢ) to the (i, parent) and (parent, i) cells, and 1/(4dᵢ) to the (parent, parent') cells for each pair of present parents.

Contributions are accumulated as COO triplets and assembled with sparse, which sums duplicate (i,j) entries. Exact nonzero counts are precomputed so the triplet arrays are allocated once at the right size.

QuantitativeGenetics.build_mme — Method
build_mme(y, X, effects; ordering=:auto) -> MMEWorkspace

Construct the mixed model equations for y = Xβ + Σ Zᵢuᵢ + e and precompute every structure that does not depend on the variance components.

ordering selects the fill-reducing permutation strategy:

  • :auto (default) — build both the fixed-effects-last ordering and CHOLMOD's default AMD, factor symbolically with each, and keep whichever yields fewer nonzeros in L. Costs two symbolic analyses once, at setup.
  • :fixedlast — force AMD on the random-effect block with fixed effects appended at the end.
  • :amd — force CHOLMOD's default ordering on the whole matrix.

This is the only place the design of C is decided; everything downstream just updates values.

Factorize the current C. The first call performs the fill-reducing analysis and caches the symbolic factor; every later call is an in-place cholesky! that reuses it and redoes only the numeric work.

QuantitativeGenetics.fit_reml — Method
fit_reml(y, X, effects; kwargs...) -> REMLResult

Estimate variance components by AI-REML and return the fit with BLUE/BLUP.

Keyword arguments:

  • start — initial [σ²₁ … σ²ₖ, σ²ₑ]. Default splits var(y) evenly between the residual and the random effects.
  • maxiter — iteration cap (default 50).
  • tol — convergence tolerance on the relative change in θ (1e-8).
  • gtol — convergence tolerance on the scaled score (1e-6). Checked before each step, so the iteration stops as soon as the optimum is reached instead of taking further no-op steps that each cost a full selected-inversion sweep.
  • trace_method — :auto (default), :exact (Takahashi) or :hutchinson. :auto inspects the factor's fill and switches to Hutchinson probing above 20k nonzeros in L, which measurement puts well below the point where the exact sweep starts to dominate.
  • nprobe — probes per trace when Hutchinson probing is used (100). Accuracy improves only as √nprobe while cost is linear: measured at q = 2000, going from 50 to 800 probes cut the relative error in σ²ₐ from 4e-4 to 2e-4 while costing 4× the time. Raise it only if you need variance components to better than ~1e-3, and prefer trace_method = :exact for that instead.
  • ordering — MME ordering strategy, see build_mme.
  • verbose — print per-iteration −2logL and components.

The iteration is AI-Newton on the LOG scale (so variances stay positive by construction), with step halving whenever −2logL fails to decrease, and an EM-REML fallback step when the AI direction is not a descent direction. EM is slower but monotone and cannot leave the parameter space; the hybrid is what makes AI-REML robust on hard data, and it reuses the trace terms the score has already paid for.

QuantitativeGenetics.heritability — Method
heritability(r::REMLResult; effect=1) -> (h², se)

Narrow-sense heritability of the given random effect: σ²ᵢ / Σσ², with a delta-method standard error from the fit's vcov.

QuantitativeGenetics.hutchinson_trace — Method
hutchinson_trace(F, B, offset, m; rng=Random.default_rng()) -> Float64

Monte-Carlo estimate of tr(B · C⁻¹[block, block]) by Hutchinson probing: E[vᵀBC⁻¹v] = tr(BC⁻¹) for Rademacher v. Each probe is one solve against the cached factor F, so this costs m solves and no selected inversion.

Cheaper than exact Takahashi on very large pedigrees, but the estimate is noisy (relative error O(1/√m)), which makes REML convergence stochastic. Use trace_method = :hutchinson only when the exact sweep is the bottleneck.

QuantitativeGenetics.meuwissen_luo — Method
meuwissen_luo(sire, dam) -> Vector{Float64}

Inbreeding coefficients by the Meuwissen & Luo (1992) algorithm.

Fᵢ = ½·a(sireᵢ, damᵢ), and that single relationship is obtained by walking the ancestors of animal i rather than by building any part of A. For each animal the algorithm accumulates, for every ancestor j, the partial contribution L[j] of j to i's two gametes; the inbreeding then falls out as Σⱼ L[j]²·dⱼ − 1.

Ancestors are processed in DECREASING index order, which is what makes a single pass correct: because the pedigree is topologically sorted, an animal's parents always have smaller indices, so popping the largest pending index guarantees every contribution to a node has been accumulated before that node is expanded. A boolean inset guard keeps each ancestor on the work list exactly once.

Work vectors are allocated once and cleared only over the ancestors actually touched, so the per-animal cost is proportional to its ancestor-set size rather than to q.

QuantitativeGenetics.reml_gradient_ai! — Method
reml_gradient_ai!(rw, y, θ; trace_method=:exact, nprobe=50, rng)
    -> (score, AI, minus2logL)

Score vector and average-information matrix at θ, assuming reml_objective! has just been called at the same θ (so the factor and solution are current).

The score's trace terms come from the selected inverse (:exact) or Hutchinson probing (:hutchinson). The AI matrix costs k+1 solves against the existing factor and no traces — see the header.

Returned quantities are derivatives of −2logL, so the Newton step is θ ← θ − AI⁻¹·(score/2); the driver handles the scaling.

selected_inverse(C::SparseMatrixCSC) -> SelectedInverse

Compute the selected inverse of the symmetric positive-definite C by the Takahashi equations, via an LDLᵀ factorization.
